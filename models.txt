# Models for local-llm-agent-benchmark
#
# Separates models into two roles (see README.md architecture diagram):
#   - Reasoners: analyze the problem statement and decide WHAT should change
#     (agents/reasoner.py). Generally benefits from a stronger/larger
#     general-purpose model since this is the "thinking" half of the loop.
#   - Actioners: take the reasoner's plan and decide HOW to execute it as
#     concrete tool calls -- read/write files, run commands, run tests
#     (agents/actioner.py, agents/agent.py). Code-specialized models tend
#     to do well here.
#
# A model can appear in both lists (e.g. as a single-model baseline, see
# configs/single_model.yaml) -- experiments/run_grid_search.py will still
# pair it with itself as one combination.
#
# IMPORTANT: this starting list only includes the models already referenced
# elsewhere in this project (configs/*.yaml, README.md). It does NOT know
# what you actually have pulled locally. Before running the grid search,
# check what's available with:
#     ollama list
# and edit the two sections below to match -- pull anything missing with
# `ollama pull <model>`.
#
# Format: one model id per line under each [section] header. Lines starting
# with # are comments and blank lines are ignored.
